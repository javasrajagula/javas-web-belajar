# Academy OS Ω — Personal Learning Operating System

Academy OS Ω is a premium, lightweight personal learning operating system. Rather than navigating disconnected pages, students enter an adaptive workspace that visualizes progress, organizes course notes, and structures milestone planners.

## Core Features
1. **Module 1: Dashboard**: Track daily study goals, leveling progression, streak details, and Claude recommendations.
2. **Module 2: Second Brain**: Upload PDF, text, and documents. Automatically chunk, summarize, and generate timeline logs, flashcard decks, and socratic quizzes.
3. **Module 3: AI Tutor**: Real-time study channel featuring 5 cognitive modes (Simple metaphors, Guided teacher, Academic professor, Socratic examiner, and Dialectical debate).
4. **Module 4: Study RPG**: Level up Focus, Logic, and Discipline skill tree attributes, unlock custom titles, and claim daily milestone rewards.
5. **Module 5: Digital Twin**: Student pattern analysis tracking predicted retention rate, optimal study slots, and habit strength statistics.
6. **Module 6: Knowledge Galaxy**: Interactive node-based learning graph powered by React Flow, coloring nodes by mastery level.
7. **Module 7: Smart Planner**: Track study session lists and auto-distribute syllabus topics across custom multi-day schedules.
8. **Module 8: Exam Engine**: Adaptive diagnostic exam engine with timer countdowns, accuracy counters, and detailed answer explanations.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Interactions**: React Flow (Node Map)
- **Content Parsing**: React Markdown
