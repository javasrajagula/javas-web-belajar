# Local Setup & Installation

To boot up the Academy OS Ω environment on your machine:

## Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

## Setup Steps
1. Clone or extract the project directory:
   ```bash
   cd academy-os-omega
   ```

2. Copy the sample environment file and configure variables (optional for local mock execution):
   ```bash
   cp .env.example .env
   ```

3. Install packages:
   ```bash
   npm install
   ```

4. Boot up local development dev server:
   ```bash
   npm run dev
   ```

5. Access sandbox dashboard by loading: [http://localhost:3000](http://localhost:3000)
